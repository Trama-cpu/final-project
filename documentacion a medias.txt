ANTES DE EMPEZAR:

Asegura que tengas pip instalado, para verificar:

1. Abre la ventana de comandos.
2. escribe el comando "python3 -m pip --version".
3. Si esta instalado ya, asegurate que este en la version mas nueva usando el comando "python3 -m pip install --upgrade pip".

Sabiendo que pip ya esta instalado, ahora tienes que instalar las dependencias de esta app, en este caso siendo "pymongo" y "Flask".

1. Abre POWERSHELL.
2. Usa el comando "python -m pip install pymongo" para instalar pymongo.
3. Usa el comando "python -m pip install Flask" para instalar Flask.

Con suerte, la app deveria abrir y conectarse correctamente.

Simplemente inicia "app.py", dale click a uno de los dos links y entra los credenciales de el perfil que quieras usar (listadas al fin de este documento.

Vulnerabilidades encontradas
XSS por uso de |safe.
Falta de validación de formularios.
Acceso directo a rutas administrativas.
Eliminación sin control de permisos.
Edición sin control de permisos.
Posibles ataques NoSQL por entradas no validadas.

Correcciones realizadas
Implementación de login.
Implementación de roles.
Validación de entradas.
Eliminación de |safe.
Restricción de rutas.
Uso de POST para operaciones destructivas.
Validación estricta de IDs y valores.
